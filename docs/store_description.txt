粵語懸浮詞典 - 學習粵語嘅最佳幫手！

功能特點：

- 滑鼠懸停即時查詞：將滑鼠移到任何中文字上，即刻顯示粵語發音
- 雙拼音系統：支援粵拼 (Jyutping) 同 Yale 兩種標註方式
- 英文解釋：提供詳細嘅英文翻譯同釋義
- 點擊即可展開更多例句同詳細解釋
- 8 種彈窗主題：經典、香港紅、深邃夜色、水墨、海洋、暖陽、薄荷、毛玻璃

語音朗讀（v1.1 新功能）：

- 多種語音選項：支援瀏覽器內置語音合成、高保真在線語音服務，以及本地語音生成模型
- 自然優質音色：與提供自然粵語發音的優質在線語音服務無縫集成
- 免配置即用：內置預設語音服務器，免配置即開即用，同時支持連接自定義語音服務器
- 支援 0.5x ~ 1.5x 語速調節

翻譯功能（v1.2 新功能）：

- 內置翻譯：雙擊選中文本，即時顯示普通話同英文翻譯（完全免配置，開箱即用）
- ✨ AI 語境翻譯：長按高亮詞或選區約 0.5 秒，AI 根據上下文語境解釋詞義
- 自定義 AI 服務商：支援連接使用行業標準 API 格式的自定義大語言模型端點，以及本地或雲端部署的離線模型

多語言介面（v1.3 新功能）：

- 支援繁體中文同英文介面切換
- 設定頁面、懸浮窗、翻譯彈窗全面本地化

體驗升級與修復（v1.4 新功能）：

- ✨ 互動式設定頁面：新增直觀的高保真動畫演示，輕鬆掌握「雙擊翻譯」、「長按 AI 翻譯」及「單擊發聲」的操作姿勢
- 🛡️ 排版隔離升級：修復懸浮窗字體受網頁干擾的問題，確保彈窗在頁面滾動時完美吸附固定

精簡模式與快捷選單（v1.5 新功能）：

- ✨ 全新精簡模式：懸浮窗可設定為僅顯示拼音（支持右上角角標聲調），並可一鍵點擊展開完整詞典
- 🔊 交互與發音優化：新增懸停自動發音選項，徹底移除發音延遲，操作流暢自如
- 🎨 介面自定義：高亮樣式新增至 7 種精美主題，優化設定頁面佈局
- 🌐 AI 目標語言自定義：AI 語境翻譯新增目標語言選擇（繁/簡/英/日），提供定制化解釋
- 🖱️ 右鍵快捷選單：新增右鍵網頁快捷菜單，可快速開啟/暫停詞典或切換顯示模式

數據來源：

- words.hk 粵語開放詞典
- CC-Canto 粵語詞典
- CC-CEDICT 中英詞典
- 超過 23 萬個詞條

使用方法：

- 將滑鼠移到中文字上即可查看發音
- 點擊高亮詞一下即可朗讀
- 雙擊選區即時顯示翻譯
- 長按高亮詞 0.5 秒觸發 AI 語境翻譯
