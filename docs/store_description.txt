粵語懸浮詞典 - 學習粵語嘅最佳幫手！

功能特點：

- 滑鼠懸停即時查詞：將滑鼠移到任何中文字上，即刻顯示粵語發音
- 雙拼音系統：支援粵拼 (Jyutping) 同 Yale 兩種標註方式
- 英文解釋：提供詳細嘅英文翻譯同釋義
- 點擊即可展開更多例句同詳細解釋
- 8 種彈窗主題：經典、香港紅、深邃夜色、水墨、海洋、暖陽、薄荷、毛玻璃

語音朗讀（v1.1 新功能）：

- 支援 4 種語音引擎：Chrome TTS、Edge TTS、Azure Speech、Bert-VITS2
- Azure Speech 提供 3 種高品質粵語音色（曉曼、曉佳、雲龍）
- Edge TTS 同 Azure Speech 提供預設伺服器，免配置即可使用
- 支援 0.5x ~ 1.5x 語速調節

翻譯功能（v1.2 新功能）：

- Bing 翻譯：雙擊選中文本，即時顯示普通話同英文翻譯（免費免配置）
- ✨ AI 語境翻譯：長按高亮詞或選區約 0.5 秒，AI 根據上下文語境解釋詞義
- 支援所有 OpenAI 兼容 API（DeepSeek、火山引擎、Ollama、OpenAI 等）

多語言介面（v1.3 新功能）：

- 支援繁體中文同英文介面切換
- 設定頁面、懸浮窗、翻譯彈窗全面本地化

體驗升級與修復（v1.4 新功能）：

- ✨ 互動式設定頁面：新增直觀的高保真動畫演示，輕鬆掌握「雙擊翻譯」、「長按 AI 翻譯」及「單擊發聲」的操作姿勢
- 🛡️ 排版隔離升級：修復懸浮窗字體受網頁干擾的問題，確保彈窗在頁面滾動時完美吸附固定

數據來源：

- words.hk 粵語開放詞典
- CC-Canto 粵語詞典
- CC-CEDICT 中英詞典
- 超過 23 萬個詞條

使用方法：

- 將滑鼠移到中文字上即可查看發音
- 點擊高亮詞一下即可朗讀
- 雙擊選區觸發 Bing 翻譯
- 長按高亮詞 0.5 秒觸發 AI 語境翻譯

隱私：本擴展不收集任何用戶數據。AI 翻譯使用用戶自己配置嘅 API，數據直接發送至用戶選擇嘅 AI 服務商。
