# v1.3.0 TODO - 用戶貢獻詞彙功能

## 功能概述

用戶在使用詞典時，若遇到數據庫中未收錄的粵語詞彙，可一鍵提交至服務器。經開發者審核後，該詞彙將被加入詞典數據庫，未來所有用戶都能查到該詞。

## 用戶體驗流程

1. 用戶選中一段文本（該文本查詞時顯示「未收錄」）
2. 彈窗中出現「📤 提交此詞彙」按鈕
3. 用戶點擊後，自動上傳：
   - 選中的詞彙
   - 所在的完整句子（上下文）
   - 提交時間
4. 顯示「✅ 已提交，感謝貢獻！」
5. 開發者在後台審核 → 通過後加入 dictionary.json → 下次更新生效

## 關於用戶賬號

**v1.3 不需要賬號系統。** 採用匿名提交 + 頻率限制方案：
- 用戶無需登錄即可提交
- 用 `chrome.storage.local` 記錄本地提交歷史和每日計數
- 服務端用 IP 限流防止濫用
- 未來如需追蹤貢獻者，可考慮 Google OAuth 可選登錄
